### 场景 1：向总监汇报季度成果，同时坦承一个项目延期

**背景：** 你是 Tech Lead，向总监做季度汇报。两个项目提前交付，但一个关键功能没达到预期。你想说服总监不要推迟整个发布，而是先砍掉一部分功能。

**你需要用到这些语块（至少5个）：**
recap / ship ahead of schedule / fall short / cut ... up front / come down to / get behind / boil the ocean

**你的版本：**

<details>

**参考答案：**

**A (You - Tech Lead):** Thanks for the time, Sarah. Quick **recap** of the quarter — we **shipped** the migration **ahead of schedule** and the observability dashboard went out last week too.
（感谢你有时间，Sarah。快速回顾一下这个季度——迁移项目提前交付了，可观测性看板上周也发布了。）

**B (Sarah - Director):** Nice work on the early delivery. What about the recommendation engine?
（提前交付干得好。推荐引擎呢？）

**A:** That's where I have to be honest — we **fell short** of the accuracy target. We hit 82% instead of the 90% we promised.
（这里我必须坦白——我们没有达到准确率目标。做到了82%，不是我们承诺的90%。）

**B:** That's a significant gap. What's your recommendation?
（差距不小。你的建议是？）

**A:** I'd suggest we **cut the personalization module up front** and ship the base model now. It **comes down to** this: do we want to **boil the ocean** and delay everything, or ship value now and iterate?
（我建议前期先砍掉个性化模块，先上基础模型。归根结底就一个问题：我们要贪大求全把所有东西都推迟，还是先交付价值再迭代？）

**B:** I can **get behind** that approach. Ship the 80% solution, learn from real data.
（我支持这个方案。先上80%的方案，从真实数据中学习。）

**A:** Exactly. We can add personalization in Q3 once we have production data to train on.
（没错。等Q3有了生产数据可以训练，再加个性化。）

**语块命中：** recap ✓ / ship ahead of schedule ✓ / fall short ✓ / cut ... up front ✓ / come down to ✓ / boil the ocean ✓ / get behind ✓ (7/7)

</details>

### 场景 2：方案评审会上，有人提出一次性重构，你反对并争取渐进方案

**背景：** 架构评审会。一位资深工程师提出 "big-bang" 重构方案，要停掉所有新功能三个月做全面重构。你反对，认为风险太大。你提前和两位同事通过气，他们也支持你的渐进方案。

**你需要用到这些语块（至少5个）：**
hit a ceiling / good catch / lead with / go sideways / big-bang / socialize with / give the green light / warming up to

**你的版本：**

<details>

**参考答案：**

**A (You - Senior Engineer):** I want to **lead with** the data here — we've **hit a ceiling** on query performance. Something needs to change, I agree with Mark on that.
（我想先摆数据——查询性能已经到瓶颈了。确实需要改变，这一点我同意 Mark。）

**B (Mark - Staff Engineer):** So you're supporting the full rewrite?
（所以你支持全部重写？）

**A:** Actually, I'd push back on the **big-bang** approach. If we pause feature work for three months, the product roadmap **goes sideways**. I've **socialized** a phased approach **with** the frontend and infra leads, and they're on board.
（其实，我反对一次性大改。如果停三个月新功能，产品路线图就跑偏了。我已经提前和前端、基础设施负责人通过气，提了分阶段方案，他们都支持。）

**B:** Fair point. But can a phased migration actually solve the core issue?
（有道理。但分阶段迁移真能解决核心问题吗？）

**A:** **Good catch** — yes, because the bottleneck is specifically in the indexing layer. We migrate that first, measure, then move to the query layer.
（好问题——能解决，因为瓶颈具体在索引层。我们先迁移这层，看数据，再处理查询层。）

**B:** I'm **warming up to** this. Can you write up a two-phase plan by Friday? If it checks out, I'll **give the green light**.
（我开始接受这个思路了。你能在周五前写个两阶段计划吗？如果没问题，我就批。）

**语块命中：** lead with ✓ / hit a ceiling ✓ / big-bang ✓ / go sideways ✓ / socialize with ✓ / good catch ✓ / warming up to ✓ / give the green light ✓ (8/8)

</details>

### 场景 3：搬进新办公室，和来参观的同事闲聊

**背景：** 你刚搬到新工位，同事路过看到你。你聊聊新环境、附近发现了什么好吃的、正在找什么东西。气氛轻松友好。

**你需要用到这些语块（至少5个）：**
take the plunge / a mixed bag / settle in / stumble upon / on the hunt for / survive on / claim one's spot / sounds like a plan

**你的版本：**

<details>

**参考答案：**

**A (Tom - colleague):** Hey! Finally **took the plunge** and moved to the new office, huh? How's it treating you?
（嘿！终于下决心搬到新办公室了？感觉怎么样？）

**B (You):** Hey Tom! Yeah, it's been **a mixed bag** honestly. Loving the natural light, but the construction next door is brutal.
（嘿 Tom！是啊，说实话喜忧参半。自然光是不错，但隔壁装修太残暴了。）

**A:** Ha, I can imagine. Have you **settled in** yet, or still living out of boxes?
（哈哈能想象。你安顿下来了没，还是还住在纸箱里？）

**B:** Mostly settled. I just **claimed my spot** by the window — best seat in the house. Oh, and I **stumbled upon** this amazing noodle place two blocks away.
（基本安顿了。我刚占了窗边的位置——全场最佳座位。对了，我偶然发现两个街区外有家超好吃的面馆。）

**A:** Oh nice! I'm **on the hunt for** a good lunch spot ever since the deli closed. We should go sometime.
（不错！自从那家熟食店关了，我一直在找好的午餐去处。改天一起去。）

**B:** I'm basically **surviving on** their dan dan noodles right now. Let's go Friday?
（我现在基本就靠他们的担担面维持生命了。周五去？）

**A:** **Sounds like a plan!** I'll find you at noon.
（就这么定了！中午来找你。）

**语块命中：** take the plunge ✓ / a mixed bag ✓ / settle in ✓ / claim one's spot ✓ / stumble upon ✓ / on the hunt for ✓ / survive on ✓ / sounds like a plan ✓ (8/8)

</details>
